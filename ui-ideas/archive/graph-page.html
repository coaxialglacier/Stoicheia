Each box is a concept at one level. A line goes from a concept down to a concept it needs. The numbers are the order you learn them in. A dashed box is a concept you know. It has no number, because it is not taught here, and you can still click it to open its page.

Graph and Page, with views. The graph has two sections: the code on top, and memory below it. Each concept has up to three views, shown as tabs: What it is, which answers four questions, then Parts and Steps, then In memory.

Captured variables starts with what it is and how its code runs. Stack frame, Heap object, and Closure value come after that, right before its In memory view.

A closure starts as known, so it is a dashed box. Click it to open its whole page, or remove it in What I know to make it number 1. → runs the next step of a program, and then goes on to the next view.

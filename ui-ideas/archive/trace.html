Trace. A candidate format, rebuilt from idea A. It is used for code that repeats, such as a loop in an algorithm, where the values change on every pass.

Each press of Next runs one pass. The pass is added as a row, and the rows before it stay, so every value the variables had is on the page. The array shows which numbers are still in range.

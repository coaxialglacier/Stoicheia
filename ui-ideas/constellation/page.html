Captured variables

✦
What it is Parts and Steps In memory V

IWhat is it?

A captured variable is a variable, declared outside a closure, that the closure's body uses. The closure uses that same variable, not a copy of it.

IIWhat problem does it solve?

A closure sometimes needs to keep a value between its calls. counter() has to keep how far it has counted. A captured variable does this without a global variable or a class.

IIIHow does it work?

The closure keeps count itself, so every call of counter() changes the same count. The first call makes it 2, and the second makes it 4. This still works after makeCounter(step:) has returned, because the closure still has count.

IVWhen do you use it, and when don't you?

Use one when a closure has to keep or change a value between calls, or change a value that the code around it reads afterward:

func total(of prices: [Int]) -> Int { var sum = 0 prices.forEach { sum += $0 } return sum } print(total(of: [3, 4])) // 7
